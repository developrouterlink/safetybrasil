# Safety Brasil 

Portal institucional e plataforma da **Safety Brasil** — Soluções integradas em Segurança e Saúde no Trabalho, Meio Ambiente e Conformidade Legal com mais de 45 anos de atuação.

---

## Tecnologias

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Design System:** Meta Clean / Optimistic Typography
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Validação de Schemas:** [Zod](https://zod.dev/)
- **Data Fetching:** [TanStack Query](https://tanstack.com/query)

## Como Executar

### Pré-requisitos
- Node.js 20+
- npm ou pnpm ou yarn

### Instalação
```bash
npm install
```

### Desenvolvimento
```bash
npm run dev
```
Acesse [http://localhost:3000](http://localhost:3000).

### Build de Produção
```bash
npm run build
npm run start
```

### Linting
```bash
npm run lint
```
